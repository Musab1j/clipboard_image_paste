# clipboard_image_paste_android example

This package is the endorsed Android implementation of
[`clipboard_image_paste`](https://pub.dev/packages/clipboard_image_paste).
Apps don't depend on it directly; add `clipboard_image_paste` and it is
included automatically.

See the [`clipboard_image_paste` example app](https://github.com/Musab1j/clipboard_image_paste/tree/main/packages/clipboard_image_paste/example)
for a full demo.
